# My Portfolio

This folder contains the source code for **Abdulhameed | The Digital Architect**.

## Website files

The deployable website is inside `dist/`:

- `index.html` — page structure and copy
- `styles.css`, `automation.css`, and `copy4.css` — visual design and responsive layout
- `config.js` — brand details, services, and portfolio records
- `app.js` — website interactions
- `assets/` — portfolio images and favicon

To preview the website locally, serve this folder with any static web server and use `dist/` as the public directory.

The brand name can be changed from the `brand.name` value in `dist/config.js`.
